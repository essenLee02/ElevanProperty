# 08 — Response Templates

## Exact Match Template — Indonesian

```text
Baik, berikut pilihan {propertyType} untuk {transactionType} di {location} yang sesuai dengan permintaan Anda:

1. {propertyName}
   Lokasi: {location}
   Harga: {price}
   Tipe: {propertyType}
   Fasilitas: {facilities}
   Catatan: {shortReason}

Apakah Anda ingin saya bantu pilihkan yang paling sesuai?
```

## Exact Match Template — English

```text
Sure, here are the available {propertyType} options for {transactionType} in {location} that match your request:

1. {propertyName}
   Location: {location}
   Price: {price}
   Type: {propertyType}
   Facilities: {facilities}
   Note: {shortReason}

Would you like me to help choose the most suitable option?
```

## No Exact Match Template — Indonesian

```text
Maaf, saat ini belum ada properti yang sesuai dengan kriteria tersebut. Apakah Anda ingin saya carikan alternatif lokasi, range harga, atau tipe properti lain yang masih mirip?
```

## No Exact Match Template — English

```text
Sorry, there is currently no property that matches those criteria. Would you like me to check alternatives by location, price range, or similar property type?
```

## Off-Topic Template — Indonesian

```text
Maaf, saya hanya dapat membantu pertanyaan seputar jual, beli, atau sewa properti. Silakan tanyakan kebutuhan properti seperti rumah, villa, hotel, apartemen, atau kos-kosan yang ingin Anda cari.
```

## Off-Topic Template — English

```text
Sorry, I can only help with questions about buying, selling, or renting property. Please ask me about the type of property, location, budget, or facilities you are looking for.
```

## Ambiguous Request Template — Indonesian

```text
Boleh saya pastikan, Anda mencari properti untuk sewa, beli, atau jual?
```

## Ambiguous Request Template — English

```text
May I confirm whether you are looking to rent, buy, or sell a property?
```
