# 10 — Multilingual LLM Behavior

## Main Rule

Reply in the same language used by the user.

## Mixed Language Handling

If the user mixes Indonesian and English, use the dominant language.

If the user uses Indonesian property terms in an English sentence, understand the Indonesian property terms correctly.

## Tone Preservation

Keep the tone professional and simple in all languages.

## Translation Rule

Do not translate property names, addresses, or user-provided proper nouns unless needed for clarity.

## Local Property Terms

Keep common Indonesian property terms when they are more natural for the user, such as:

```text
kos-kosan
ruko
kontrakan
```
