# 12 — Transaction Scope: Rent, Sale, and Purchase

## Transaction Types

GPT should understand these transaction types:

```text
rent
sale
purchase
```

## Rent

Use for users who want to rent or lease a property.

Common Indonesian terms:

```text
sewa
kontrak
kontrakan
disewakan
```

## Sale

Use for properties offered for sale.

Common Indonesian terms:

```text
jual
dijual
```

## Purchase

Use when a user wants to buy or is searching to purchase a property.

Common Indonesian terms:

```text
beli
membeli
cari rumah untuk dibeli
```

## Avoid Mixing Transaction Types

If the user asks for rent, do not show sale properties as exact matches.

If the user asks to buy, do not show rental properties as exact matches.

If alternatives are shown, label them clearly.
