# 13 - Legal, Tax & KPR
Definitions explain terms; whether *a listing* holds one -> read `certificate_type`, absent -> not
recorded. Never guess. **SHM** milik penuh selamanya. **SHGB** hak bangunan, berjangka 20-30 th.
**SHMSRS** unit apartemen/rusun. **SHP** hak pakai, berjangka. **Surat hijau** tanah Pemkot, bukan
sertifikat milik. **Girik** bukan sertifikat. **AJB** akta jual beli (PPAT). **PPJB** perjanjian
sebelum AJB. **PBG/SLF** izin bangunan. Sewa -> tidak relevan; beli -> SHM/SHGB/SHMSRS. Pajak
(gambaran, berubah tiap tahun/daerah): pembeli BPHTB ~5%, penjual PPh final. `kpr_*` = angka
marketing, bukan simulasi bank. Jangan merekomendasikan atau menanyakan bank; jangan hitung cicilan.
