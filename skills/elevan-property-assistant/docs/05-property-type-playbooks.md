# 05 - Property-type playbooks
Docs 02-03 still rule; add only the 1-2 distinctive questions per type, after the listings, one at a time.

| Type | Distinctive slots (in order) | Skip |
|---|---|---|
| Hotel | purpose · check-in + nights · guests · room type · breakfast; beli: operational vs land, rooms, operator, ROI | furnishing, duration |
| Villa | period (malam/minggu/bulan) · check-in + nights · guests · private pool; beli: use, SHM vs leasehold | furnishing (nightly) |
| Kos | putra/putri/campur · KM dalam/luar · AC/WiFi · listrik include · meals; beli: rooms, ROI | - |
| Ruko | business type FIRST · floors · frontage (m) · parking · hook/corner | occupants, furnishing |
| Kantor | headcount (~5-7 m2/orang) · grade A/B/C · fit-out vs shell · service charge · parking; beli: SHMSRS | bedrooms, furnishing |
| Gudang | purpose FIRST · m2 · ceiling height · loading docks · KVA · zoning; cold storage -> temperature | bedrooms, furnishing |
| Toko | business type · mall vs standalone · m2 · frontage · foot traffic; popup -> exact weeks | bedrooms, furnishing |
| Mansion | bedrooms · private pool · smart home (which systems) · staff quarters · garage capacity | - |
| Kondotel | unit type · operator brand · ROI/revenue share · management fee · SHMSRS | furnishing |
| Others (tanah, kavling, SPBU, pabrik) | purpose FIRST · matang vs perlu IMB · m2/ha · zoning/izin; pertanian -> irigasi; pabrik -> KVA | bedrooms, furnishing |

Orientation answers ("hadap barat", "hindari matahari terbenam", "lantai 12-15") are valid Q12 - record as `Tower/Lantai`.
Summary frames: LEASE adds Durasi/Furnitur; SALE adds Pembiayaan/Use; BOOKING adds Check-in/Malam/Tamu/Breakfast and has **no furnishing line**.
