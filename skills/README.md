# Consolidated Skills Package

This package merges the previous skill documentation into two clean skill groups only:

1. `chat_gpt_reponds`
   - GPT response behavior skill.
   - Used to guide how the property chatbot should answer customers.

2. `website_env_concept`
   - Website environment and development skill.
   - Used to guide backend, frontend, database, Google API, Fonnte API, ChatGPT API, chatbot workflow, JSON property data, and deployment/testing.

## Cleanup Result

Redundant and looping documentation from the old package has been removed and merged.

Old duplicated folders such as `property-ai-skill`, `property-ai-website-skills`, repeated module docs, repeated chatbot docs, repeated API docs, and repeated environment notes are consolidated into these two final folders.

## Recommended Usage

- Use `skills/chat_gpt_reponds` for response/prompt behavior.
- Use `skills/website_env_concept` for website code and integration development.
