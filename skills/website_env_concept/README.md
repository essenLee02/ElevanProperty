# Website Environment Concept — Code Aligned Documentation

This documentation has been aligned with the actual backend and frontend code inside `ElevanLabs.zip`.

No backend or frontend code was changed.

This ZIP only contains updated `.md` documentation files.

## Important Current-Code Summary

The current website code is a VueJS + NodeJS landing page with:

- Home page
- About Us page
- Contact page
- Contact Form validation
- Contact Form submission to backend
- Google Sheets integration through Service Account JSON
- MySQL save through Sequelize
- Basic user activity logging to console
- About page portfolio generated in frontend
- Basic route logging from Vue Router

The current code does **not yet implement**:

- Floating chatbot component
- ChatGPT / OpenAI API integration
- Fonnte WhatsApp API integration
- ChatSession model
- ChatMessage model
- Property model
- Dedicated backend services folder
- Frontend modular API files such as `contactApi.js` or `chatbotApi.js`

Those features are documented as **planned / future development**, not as current implemented behavior.
