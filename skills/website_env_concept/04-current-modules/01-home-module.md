# Home Module

## Current Status

Implemented as a static Vue page.

## Frontend File

```text
frontend/src/views/HomeView.vue
```

## Backend API

```text
GET /api/home
```

Current backend API returns only a welcome message.

## Current Content

Home page includes:

```text
hero section

business story / reasons

CTA to About page
```

The frontend Home page does not fetch dynamic content from `/api/home`.
