# AI Recommendation Engine

## Recommendation Rules
The chatbot should recommend properties that match:
- intent
- property type
- size requirements
- location
- budget
- facilities
- rental duration
- occupancy constraints

## Fallback Behavior
If no exact match is found, the chatbot should:
- offer similar alternatives
- suggest nearby locations
- suggest adjusted budget options
- ask whether the customer wants more recommendations

## Ranking Signals
- location match
- budget fit
- property type match
- size fit
- required facility coverage
- freshness / availability
- negotiation potential
