# AI Intent and Discovery Logic

## Primary Intents
The chatbot should identify whether the customer wants to:
- buy a property
- rent a property

## Property Types
- house
- hotel
- villa
- boarding house
- apartment
- others

## Property Detail Questions
- land size
- building size
- number of bedrooms
- number of bathrooms
- floors
- parking space
- garden/backyard

## Detailed Preferences
- furnished or unfurnished
- modern or traditional
- near schools, offices, malls, hospitals
- pet-friendly
- security features
- budget range

## Rental-Specific Questions
- required facilities
- rental duration
- occupancy information
