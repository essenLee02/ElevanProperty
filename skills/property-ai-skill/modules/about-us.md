# Module: About Us

## Purpose
The About Us page showcases the company's portfolio and credibility.

## Required Features
- portfolio cards
- property images
- transaction type filter:
  - buy
  - rent
  - sell
- property type filter:
  - villa
  - house
  - boarding house
  - hotel
  - apartment
- display fields:
  - title
  - location
  - address
  - price
  - transaction type
  - property type
  - image

## Best Practice Additions
- Add quick tags for area, budget tier, and furnishing status
- Add card click-through to property detail page
- Support lazy loading for image-heavy pages
- Include CTA to ask the chatbot for similar listings
