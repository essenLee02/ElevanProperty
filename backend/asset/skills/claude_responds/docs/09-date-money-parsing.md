# 09 - Date & Money
"25 agustus" -> that date (next year if past); "2 minggu lagi" -> today+offset; "belum ada target" ->
none. Survey date is not the move-in date. 50jt -> 50.000.000; "2-3 juta" -> range; "terjangkau" ->
not a number. Units on the price (/bulan, /minggu, /malam) beat any duration elsewhere.
