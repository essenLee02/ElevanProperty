# Deployment ke Hostinger 

## Cara Deploy Aplikasi Node.js

1. Buat server di Hostinger (VPS atau Cloud)
2. Install Node.js dan NPM
3. Clone repository Git atau upload kode sumber
4. Jalankan  untuk menginstall dependencies 
5. Buat file ecosystem.config.js untuk konfigurasi PM2
6. Jalankan  untuk start aplikasi

## Cara Deploy Aplikasi PHP

1. Buat hosting atau VPS di Hostinger
2. Login ke cPanel atau SSH  
3. Upload file PHP atau clone repo Git
4. Edit file konfigurasi (misalnya .htaccess, php.ini)  
5. Pastikan web server (Apache/Nginx) dan PHP berjalan
6. Akses aplikasi melalui domain/IP untuk test  

## Cara Deploy Aplikasi Java (Tomcat/Jetty) 

1. Sewa VPS atau Cloud Hosting di Hostinger
2. Login via SSH sebagai root
3. Install OpenJDK atau JDK  
4. Download Apache Tomcat atau Jetty 
5. Ekstrak dan setting PATH
6. Buat file .war dari kode Java  
7. Deploy file .war ke folder webapps
8. Restart server Tomcat/Jetty
9. Akses aplikasi via IP:8080 atau domain
